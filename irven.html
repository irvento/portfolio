Underworld Legends

Underworld Legends was created during my freshman year 2021-2022. This project is inspired by Kaarin Gaming's Platformer Tutorial from YouTube. I modified and enhanced Kaarin's single-player game into a Player vs. Player experience, implementing fun and interactive gameplay mechanics. The game features pixel art graphics, multiple levels, and various character abilities, providing an engaging experience for the players.
